About

BasaltOS

BasaltOS is a hardened Linux operating system by Cody Hadley. It is built on Debian stable, and it stays there. It is not a rolling release.

There are two editions. Core is the bare base: no web admin UI and no add-ons, for manual configuration. Server is the full edition, with Strata Desktop (a Wayland session on labwc) and a web admin UI.

This website is the public home. Disk images will be published on this repository's Releases, each with a SHA256SUMS file. The public address for the site is codeman86.github.io/basaltos-site.
