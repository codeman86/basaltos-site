Checksums

Check the file before you boot it

Download the ISO and the SHA256SUMS file from the same release into one directory. The sums file names the ISO. If the check fails, do not boot that file.

Linux, with GNU sha256sum

sha256sum -c SHA256SUMS

macOS

shasum -a 256 -c SHA256SUMS

You can also print one digest and compare it to the matching line in SHA256SUMS:

sha256sum basaltos-1.0-server-amd64.iso
