Roadmap

What comes next

These are planned. The release model is already decided: BasaltOS stays on Debian stable. It is not a rolling release.

  1. App Store

    Debian packages first, then Flathub.

  2. Welcome

    A first-login app, with an optional Creator's Picks list. Each pick is a checkbox.

  3. Update settings

    Three modes: automatic, security-only, and download-and-notify.

  4. NVIDIA driver helper

    A helper for NVIDIA drivers, including Kepler-generation cards.

  5. Community add-ons

    Add-ons from the community, on top of the full edition.

  6. Tiling mode

    A tiling mode for Strata Desktop.

  7. Settings redesign

    A new layout for Settings.
