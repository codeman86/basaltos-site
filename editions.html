Editions

Core and Server

One hardened Debian base, two images. Core is for manual configuration. Server is the full edition.

What each edition includes
Feature Core Server
Role Bare base for manual configuration Full edition
Base Hardened Debian stable, amd64 Hardened Debian stable, amd64
Web admin UI No Yes
Add-ons None Part of the full edition. Community add-ons are planned.
Strata Desktop Not included Included. Wayland session on labwc.

Core

Configure it yourself

Core is the hardened Debian base with no web admin UI and no add-ons. Use it when you want to build the system up by hand.

Server

Desktop and web admin

Server adds Strata Desktop and the web admin UI on that same base. This is the edition the screenshots on the Features page come from.
